Site Audit

Fetches every page from your sitemap the same way Googlebot does — via a server-side function that requests each page with a bot User-Agent, so it gets the fully prerendered HTML from functions/_middleware.ts rather than the empty SPA shell. Checks for broken pages, missing or truncated meta tags, missing H1s, images without alt text, broken schema, and known stale phrases from past cleanups.

Must be opened from the live site (not a downloaded file). Requires functions/api/audit-fetch.ts to be deployed.
